# 探索からボス戦への流れ

- 開始から30秒間はボスを出さず、水平方向の移動を制限しません。海底タイル・水面・海中の背景は移動先にも描画されます。
- 30秒時点のプレイヤー座標を戦闘エリアの中心として固定します。以降、中心は追従しません。
- 10秒かけて正方形の一辺を300から240に縮めます。青い境界が行動範囲を表し、プレイヤーは外へ出られません。水深制限・海底との衝突は従来どおりです。
- 30〜40秒は操作と攻撃を停止する登場演出です。固定カメラの右奥から船が接近→柵を設置する場面（2〜4秒）で下降を描画→太陽を見上げる→右から船が飛び込み、太陽を遮ってから落下→着水の水しぶき・波紋・カメラ振動→元のカメラへ復帰します。探索中のF6で待ち時間を飛ばして確認できます。
- 40秒でボス戦が始まります。高さ25.5を維持し、固定中心から半径35の軌道を移動します。
- ポーズ中は探索時間・縮小・生物補充も停止します。

海洋生物・装備は未装着のものを周辺に合計100体まで配置します（従来25体）。開始時は確定9体とランダム最大24体を配置し、以降0.125秒ごとに最大1体を補充します。約9割を海洋生物にします。探索中に150以上離れた未装着の個体を取り除き、移動先へ補充します。装着済み・投擲中の個体は距離による削除対象にしません。

画面外の未装着個体はモデル更新と描画を省略し、位置・取得判定は維持します。装着中の個体はPlayer側のみで描画します。Game Debug ControlsのFrame表示でフレーム時間とFPSを確認できます。

出現時の停止を避けるため、シーン開始時に予備136体とボスのGPUリソースを作成します。遠方の個体・投擲後に消滅した個体は破棄せず予備へ戻し、補充時は位置・状態をリセットして再利用します。初期9体を含む総数は145体で、装着・投擲中のものは再利用しません。予備が尽きたときは新規生成せず、個体が戻るまで補充を待ちます。開始時の読み込み時間・保持メモリは増えます。

ランダム補充はプレイヤーから水平距離55以上、カメラの視界外に限ります。地形補正後にも距離を確認します。箱庭内で条件を満たす場所がない場合は補充を待ち、距離条件を緩めません。開始地点の確定9体は従来どおり近くに配置します。

終了時はGPU完了を待ち、シーンのOnExitと個体の破棄を済ませてから共有アセットを解放します。出力の `[Shutdown]` は処理区間ごとの実時間（ms）で、GPU待機・個体解放・共有アセット・ドライバー終了を区別できます。

海底は既存のタイルを再利用します。開始地点にある固有のサンゴ礁・アーチはその場所に残ります。離れた場所の生物配置を永続保存する仕組みではありません。

時間と範囲は OceanBattleFlow.h、出現数と補充間隔は GameScene.cpp で調整できます。
