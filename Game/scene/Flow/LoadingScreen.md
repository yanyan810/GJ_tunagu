# ローディング画面

シーン切り替え中に `resources/tex/Load` の画像を使用します。1280×720の画像内の配置を維持し、上部にload_title、中央下に5匹、右下にload_moziを表示します。load_rotateDotは透明余白をUVで切り取り、文字の右隣を周回します。

生物は暗いシルエットを背景に、エビ→ウニ→マグロ→クラゲ→貝の順で左から色が入ります。進捗は経過秒数ではなく、シーン初期化で完了した処理段階に基づきます。100%の画面を1フレーム描画してからゲームを開始します。

SceneLoadTaskはメインスレッドの分割実行です。TitleSceneとGameSceneは環境・プレイヤー・生物・ボスなどの初期化の間に描画を挟みます。単一モデルの読み込みや環境初期化そのものが重い場合、その処理中は一時的にアニメーションが止まることがあります。他シーンは既存のOnEnterを一括実行するため、ローディング表示の途中進捗はありません。

検証: SceneLoadTaskTests.cppで遅延開始、段階ごとの進捗、完了、所有権移動、途中キャンセル、例外伝播を確認します。
