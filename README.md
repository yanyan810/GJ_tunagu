# ポストエフェクト実装

DirectX 12を使用し、ゲーム画面全体および特定のオブジェクト／パーティクルへ適用するポストエフェクトを実装しています。

## 確認方法

`CG2_Setup.exe`を起動し、タイトル画面で`Space`を押すとゲームシーンへ移動します。

| 入力／条件 | 確認できるポストエフェクト |
|---|---|
| ゲーム中に`Esc` | Grayscale、GaussianFilter |
| `U`で敵へ攻撃を当てる | 敵への赤いDepthBasedOutline、ヒットパーティクルのBloom／OutlineBloom |
| 敵の攻撃を受ける | 吹き飛ばされているプレイヤーへの赤いDepthBasedOutline |
| `I`で必殺攻撃を使用し、必殺レベルが1～3になる | プレイヤーへの黄色いLuminanceBasedOutline |
| ボスが落下攻撃を使用する | RadialBlur、着弾パーティクルのBloom／OutlineBloom |
| ステージ外周の壁へ3回接触する | 黒いDissolveによるゲームオーバーへの遷移 |
| ゲームオーバーになる | Vignetting |

## 実装したポストエフェクト

### Vignetting

画面中心からの距離を利用して、画面周辺を暗くします。ゲームオーバー画面で適用し、中央へ視線を誘導します。

### BoxFilter / Bloom

入力画像の高輝度部分を抽出し、周辺画素を参照して光を拡散させます。元画像を発光画像で置き換えず、「元画像＋発光」の形で加算合成しています。

攻撃ヒットおよびボスの落下攻撃のパーティクルへ個別適用しています。

### GaussianFilter

横方向と縦方向を分けた2パスのガウシアンフィルターです。1回の処理で二次元方向を走査する場合より、サンプリング回数を抑えてぼかせます。

ゲーム中に`Esc`でポーズすると、Grayscaleと同時にゲーム画面へ適用します。

### LuminanceBasedOutline

周辺画素との輝度差をSobelフィルターで検出し、輪郭を生成します。

プレイヤーの必殺レベルが1、2、3の間、プレイヤーだけへ黄色で適用します。攻撃方向やプレイヤーの向きには依存しません。

### DepthBasedOutline

深度差と法線差から輪郭を検出します。

- ステージの地面へ赤色で適用
- プレイヤーが敵へダメージを与えた場合、敵へ約0.2秒間適用
- プレイヤーがダメージを受けた場合、吹き飛ばされている間適用

### RadialBlur

指定した中心から放射状に複数回サンプリングし、中心から外側へ伸びる残像を生成します。

ボスの落下攻撃中にゲーム画面へ適用します。

### Dissolve

ノイズテクスチャと時間変化するしきい値を比較し、表示領域を徐々に消去します。

シーン遷移では黒いマスクとして使用し、画面が黒く覆われた時点で次のシーンへ切り替えます。

### Random

疑似乱数を用いて画面へランダムなノイズを加えます。

### Grayscale

入力画像のRGBから輝度を計算してモノクロ化します。

ゲーム中に`Esc`でポーズするとGaussianFilterと同時に適用し、ポーズ解除時に両方を解除します。

### OutlineBloom

対象のアルファと輝度から外周マスクを作成し、その輪郭へ指定色の発光を加えます。

攻撃ヒットとボスの落下攻撃のパーティクルへ適用しています。
